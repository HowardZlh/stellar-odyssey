# 交互与快捷键参考

## 鼠标操作

| 操作 | 功能 |
|---|---|
| 左键拖动 | 旋转视角 |
| 右键拖动 | 平移 |
| 滚轮 | 连续缩放——从行星表面到可观测宇宙边界无缝遨游，跨层级自动切换内容/时间压缩/音景 |
| 左键点击天体 | 选中并打开信息面板（名称/类型/真实物理参数/数据来源 + 飞往/跟随按钮） |
| 点击剖面分层 | 太阳剖面模式下点选核心/辐射区/对流区查看科普 |

## 键盘快捷键

| 按键 | 功能 | 生效范围 |
|---|---|---|
| `1` | 行星视角（L1） | 全局 |
| `2` | 太阳系视角（L2） | 全局 |
| `3` | 银河系视角（L3） | 全局 |
| `4` | 宇宙视角（L4） | 全局 |
| `空格` | 暂停 / 继续模拟 | 全局 |
| `M` | 音效开 / 关 | 全局 |
| `O` | 轨道线显示开关 | 全局 |
| `L` | 天体标签显示开关 | 全局 |
| `R` | 真实比例模式开关 | 全局 |
| `F` | 飞往当前选中天体 | 已选中天体时 |
| `Esc` | 取消跟随 | 跟随中 |
| `[` / `]` | 巡游上一个 / 下一个天体（按当前视角域路由：行星系统 / 太阳系 / 银河系 / 宇宙序列） | 全局 |
| `G` | 银心固定视角切换（银心居中，俯瞰太阳系绕银心公转） | 仅银河系视角 |
| `V` | 垂直展开开关（银盘 morph 为椭球 + 特殊天体银纬高度展开） | 仅银河系视角 |

> 输入框聚焦时快捷键不响应。

## 控制面板详解

控制面板位于左上角，**选项按当前视角作用域智能显隐**：全局选项四视角常显，
视角专属选项只在对应视角出现（域外隐藏，但已开启的状态与场景效果保留）。

### 常显区块

| 区块 | 说明 |
|---|---|
| **视角（快捷键 1-4）** | 四视角锚点按钮，当前视角高亮 |
| **模拟速度（空格暂停）** | 暂停/继续按钮 + 速度倍率滑块（×0–×100，各视角另有差异化时间压缩比） |
| **音效（M 静音）** | 开关 + 音量滑块；真空无声，音效为艺术化设计 |

### 显示开关（全局项）

| 选项 | 说明 |
|---|---|
| 轨道线（O） | 行星/矮行星/彗星轨道（L1/L2）+ 卫星星系轨道（L4） |
| 天体标签（L） | 全层级天体名称标签（近距自动钳制尺寸不遮挡画面） |
| 真实比例模式 | 天体按真实大小线性映射——行星/矮行星极小属科学事实，可飞往近观 |
| 泛光效果（Bloom） | 发光天体辉光后处理，低性能设备可关闭 |
| 性能监控（FPS/内存） | 500ms 窗口平均 FPS + 内存占用面板 |

## 天体巡游与跟随

- **点选 → 飞往**：信息面板"飞往"按钮或 `F` 键，2.5 秒平滑运镜后进入跟随模式（相机锁定天体，仍可旋转缩放）
- **巡游序列**（`[` / `]` 或底部切换控件）按视角域路由：
  - L1：当前行星系统内循环（行星本体 + 其卫星，按绕行半长轴升序）
  - L2：行星 + 矮行星 + 彗星 15 天体（按轨道半长轴升序）
  - L3：银河系 14 站（日球层顶 → 人马座 A* → 恒星/星云/星团特殊天体）
  - L4：宇宙 8 站（本星系群成员 + M87 + 类星体 3C 273）
- **跟随 + 推近解锁近观细节层**：跟随后继续滚轮推近，按距离阈值挂载重资产近观层——黑洞光子环（人马座 A* / 天鹅座 X-1 / M87 核心）、体积星云内部、星系近观粒子云与体积尘埃盘等；拉远/换目标即自动释放（LRU 池）
- **跟随期间视角层级锁定**（不随相机距离跳级），`Esc` 或按 `1`–`4` 解除
- 通知卡片的"飞往观看"（超新星/耀斑/CME）同样进入跟随

## HUD 信息（右上角）

- 当前视角名与模拟时间（UTC）
- 当前尺度标尺（AU / 光年 / Mpc 随缩放自动切换）
- 参考系说明（日心系 / 银心系跟随太阳系 / 本星系群质心系……）
- 跟随状态与取消按钮
- 银河系视角：银河年进度（第 N 圈 + 绕行角度）与银盘面高度
- 快周期天体减速显示提示（防闪烁）
