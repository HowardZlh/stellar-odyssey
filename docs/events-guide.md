# 动态事件演示指南

星海奥德赛内置四类动态天文事件：**太阳耀斑、日冕物质抛射（CME）、超新星爆炸、星系碰撞合并**。
事件既会按物理概率自动触发，也可在控制面板手动演示。

## 事件与视角域

每类事件属于特定视角域——只在域内自动触发、显示通知与演示按钮；
**离开所属域超过 1 秒，活跃事件会被直接丢弃**（回到域内不恢复，等待下一次触发）。
域判定以**离散视角**（HUD 显示的当前视角）为准——跟随巡游天体推近拉远不会误判离域。

| 事件 | 所属视角域 | 演示按钮出现位置 |
|---|---|---|
| 太阳耀斑 | L1 行星 / L2 太阳系 | 面板"动态事件演示"区 |
| CME（含抵达地球链） | L1 行星 / L2 太阳系 | 同上 |
| 超新星爆炸 | L3 银河系 | 同上 |
| 银河系—仙女座合并预览 | L4 宇宙 | 同上 |

> 另有**常驻周期演示物**（非事件，无需触发）：L4 的伽马射线暴 GRB 221009A 以 45 秒周期
> 重放"闪光 → 相对论双喷流 → 余辉膨胀壳减暗"的完整演化，飞抵跟随即可反复观看。

## ☀️ 太阳耀斑

**是什么**：太阳活动区磁能突然释放的爆发，按 C/M/X 级分级。

**怎么触发**

1. 切到 L1/L2 视角，建议先点选太阳并"飞往"近观
2. 点击面板"☀️ 触发太阳耀斑演示（活动区随机）"
3. 或等待自动触发：泊松过程按 11 年太阳周期调制概率（活动极大期更频繁）

**看点**

- 耀斑从黑子活动区爆发，局部增亮 → 峰值 → 指数衰减（时长经减速呈现已登记）
- 通知卡片显示耀斑级别（如 M5.2），含"飞往太阳"按钮
- 强耀斑可能联动触发 CME

**注意**：太阳剖面模式开启期间耀斑按钮不可用（外部特效已淡出）。

## 🌊 日冕物质抛射（CME）

**是什么**：日冕大规模等离子体抛射，速度数百至数千 km/s；朝地球的 CME 抵达后引发地磁暴与极光。

**怎么触发**：L1/L2 下点击"🌊 触发日冕物质抛射（CME）演示"。

**看点**

- 半透明壳层从太阳表面扩张飞出（速度 km/s 实时显示）
- **若方向朝地球**：通知显示预计抵达时间，抵达后地球极区**极光增强**——切到 L1 近观地球极区
- 与耀斑同时演示可还原"耀斑 + CME"联动事件链

## 💥 超新星爆炸

**是什么**：大质量恒星演化末期的剧烈爆炸，真实频率约每 50–100 年一次/星系（模拟已加速，登记）。

**怎么触发**

1. 切到 L3 银河系视角
2. 点击"💥 触发超新星演示（旋臂内随机）"
3. 或等待泊松自动触发（银河系视角高时间压缩比下几分钟内可遇）

**看点（完整四阶段，10–30 秒）**

1. **前身星骤增亮**：数秒内亮度飙升至峰值
2. **冲击波扩张**：球形激波按 Sedov-Taylor 定律 r∝t^0.4 减速扩张（半透明壳体 + 外缘增亮）
3. **亮度指数衰减**
4. **永久遗迹归档**：膨胀星云 + 中心致密天体——前身星 ≥20 M☉ 坍缩为**黑洞**，否则为**中子星**

**技巧**

- 通知卡片点"**飞往观看**"自动运镜到爆炸现场并跟随
- 遗迹永久保留在银盘上（可开启垂直展开 `V` 观察遗迹随盘抬升）
- 爆发伴随低频冲击音效（程序化合成）

## ⏩ 银河系—仙女座碰撞合并预览

**是什么**：银河系与仙女座星系（M31）正以 ~110 km/s 相互接近，约 45 亿年后碰撞合并为椭圆星系 "Milkomeda"。

**怎么触发**：切到 L4 宇宙视角，点击"⏩ 预览银河系—仙女座碰撞合并"。

**看点（12 秒缓动快进 45 亿年）**

1. **接近末段**：两星系相互逼近，潮汐扭曲渐显
2. **首次穿越（T0）**：两盘穿越 + 星暴增亮，弹出演化科普卡片
3. **回摆振荡**：引力拉扯下反复穿越
4. **核心并合**：双核旋进合并
5. **终态 Milkomeda**：椭圆星系，HUD 阶段标签全程跟踪

**恢复**：预览结束后点"⏪ 恢复预览前时间"，模拟时间、倒计时与所有阶段状态完整复原。

## 事件机制细节

| 机制 | 说明 |
|---|---|
| 可见性与可用性双层 | 演示按钮域外**隐藏**；域内若有同类事件进行中/条件不满足则**置灰** |
| 硬隔离 | 离域 >1 秒活跃事件丢弃（锚点切换/飞往运镜期间豁免计时）；超新星被丢弃不归档遗迹，合并预览自动回跳时间 |
| 自动触发 | 耀斑/CME/超新星按泊松过程 + 视角域门控；暂停时不推进 |
| 音效联动 | 超新星低频冲击、耀斑爆发音、UI 操作音（可静音） |
