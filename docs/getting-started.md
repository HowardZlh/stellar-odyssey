# 快速上手

> 星海奥德赛 Stellar Odyssey——从行星表面到宇宙尽头的一次滚轮之旅。
> 本文带你完成安装运行，并给出第一次遨游的推荐路线。

## 环境要求

- Node.js 20+ 与 npm
- 支持 WebGL 2 的现代浏览器（推荐 Chrome / Edge，Firefox / Safari 亦可）
- 内存占用目标 < 1GB，无需独立显卡（集成显卡可流畅运行）

## 安装与运行

```bash
# 克隆仓库后安装依赖
npm install

# 启动开发服务器
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 即可进入。

生产部署：

```bash
npm run build
npm run start
```

## 30 秒了解界面

进入应用后你会看到：

| 区域 | 内容 |
|---|---|
| **左上 · 控制面板** | 视角切换 / 模拟速度 / 音效 / 显示开关 / 动态事件演示（选项随当前视角智能显隐） |
| **右上 · HUD** | 当前视角、模拟时间、尺度标尺、参考系、跟随状态、银河年进度（L3） |

## 第一次遨游：推荐路线（约 5 分钟）

1. **从地球出发**——进入应用即为行星视角（L1），跟随地球。拖动鼠标环视：可见大陆、海洋、云层与夜半球城市灯光；按 `]` 巡游地球系统：天宫 → ISS → 哈勃 → 静止卫星 → 月球。
2. **拉远看太阳系**——按 `2` 或直接滚轮拉远，八大行星沿真实开普勒轨道运转（行星位置与真实当前日期一致）。拖动速度滑块加速时间，观察水星疾驰与哈雷彗星近日点甩尾。
3. **飞往太阳**——点击太阳 → 信息面板点"飞往"，近观米粒组织与黑子；在控制面板勾选**太阳内部剖面**查看核心/辐射区/对流区分层科普；点"触发太阳耀斑演示"看一场耀斑。
4. **跃入银河系**——按 `3`，你的太阳系此刻只是"You are here"标记的一个小点。按 `G` 切换银心固定视角，俯瞰太阳系沿波浪轨道绕银心公转；按 `V` 垂直展开银盘为椭球，观察特殊天体的真实银纬分布；按 `]` 巡游 14 站深空。
5. **推近一颗黑洞**——巡游到人马座 A* 后**继续滚轮推近**：背景星场开始弯曲，光子环与多普勒增亮的吸积盘浮现——这是 raymarch 引力透镜实时渲染。再去猎户座星云站推近，钻进体积渲染的扇贝状发射腔里看四边形星团。
6. **抵达宇宙尽头**——按 `4`，本星系群尽收眼底（背景是 2MASS 红移巡天 43,488 个真实星系的点云）。飞往 M31 仙女座近观由真实照片驱动的旋臂与尘埃暗带；点击"⏩ 预览银河系—仙女座碰撞合并"，12 秒穿越 45 亿年看两个星系合并为 Milkomeda；再飞往 M87 推近核心，还原 EHT 首张黑洞照片的光子环；继续滚轮拉远，穿过室女座星系团、拉尼亚凯亚超星系团，直到可观测宇宙边界。
7. **一镜到底回家**——从宇宙边界持续滚轮放大，无需任何点击，一路缩回地球表面——这就是连续维度缩放遨游。

## 常见问题

**Q：打开后行星怎么这么小/看不见？**
默认模式下天体尺寸已做对数压缩夸大以保证可辨识。若开启了真实比例模式（`R`），行星在太阳系尺度下接近不可见属科学事实——可点选后"飞往"近距离观察。

**Q：为什么太空里有声音？**
真空无声，音效为艺术化设计（应用内已登记说明），可按 `M` 静音或在面板调节音量。

**Q：帧率不足 60 FPS？**
体积渲染（星云/黑洞/尘埃盘）自带帧率自适应降档（自动降低步数与渲染分辨率）；仍不足时可在控制面板关闭"泛光效果（Bloom）"，并勾选"性能监控"观察 FPS/内存。

**Q：端口被占用？**
使用备用脚本 `npm run dev:3100` 或 `npm run dev:3200`（各自使用独立构建目录，可与 3000 端口实例并行）。注意 Next.js 对构建目录加了互斥锁，直接 `next dev -p <端口>` 换端口会被拒绝启动。

**Q：手机/平板能玩吗？**
可以，已全站适配移动端：单指拖动旋转、双指捏合缩放、点按选中天体；小屏界面自动切换为移动布局（底部标签栏 + 抽屉面板），渲染质量按设备能力自动降档以保证流畅。完整移动端操作见 [controls.md](controls.md) 的「触屏操作」一节。
