# 启动 URL 参数

星海奥德赛支持通过 URL 查询参数配置启动行为——无需改代码即可实现**深链分享、展馆部署、合作方冠名与语言预设**。全部参数可自由组合；**非法值一律静默回退默认**，不会报错。

```
https://stellar.guushu.com/?mode=kiosk&tour=all&dwell=30&logo=https://example.com/logo.png&lang=en
```

## 参数总表

| 参数 | 合法值 | 默认 | 说明 |
|---|---|---|---|
| `body` | 任意天体 id | 无 | 加载完成后自动飞往并跟随该天体（无效 id 静默忽略） |
| `mode` | `kiosk` | 无 | 进入展馆模式（自动巡游，见下） |
| `tour` | `solar` / `galaxy` / `universe` / `all` | `solar` | 展馆模式巡游域 |
| `dwell` | 整数 `5`–`600` | `30` | 展馆模式每站停留秒数（含约 2.5 秒运镜；越界不钳制、直接回退 30） |
| `logo` | https URL（≤2048 字符） | 无 | 页面右侧角落显示合作方 logo（最大 160×40，加载失败自动隐藏） |
| `lang` | `zh` / `en` | — | 界面语言（优先级：`?lang=` > 本地存储 > 默认 zh） |

`mode` / `tour` / `lang` 大小写不敏感；同名参数重复时取第一个值。

## 深链直达（`body`）

分享一条链接，打开即飞往目标天体并进入跟随：

```
?body=jupiter        # 木星
?body=sgr-a-star     # 人马座 A* 黑洞（继续滚轮推近可见光子环）
?body=orion-nebula   # 猎户座星云（推近钻入体积渲染内部）
?body=m31            # 仙女座星系
```

天体 id 与信息面板/巡游序列一致（行星用英文名小写，特殊天体见 `src/data/specialBodies.ts` 等数据文件）。飞往在首批纹理加载完成后触发（最迟 3 秒兜底），只执行一次。

## 展馆模式（`mode=kiosk`）

面向科技馆/展厅大屏的无人值守模式：

```
?mode=kiosk                          # 默认巡游太阳系域，每站 30 秒
?mode=kiosk&tour=all&dwell=20        # 四域轮转，每站 20 秒
?mode=kiosk&lang=en&logo=https://…   # 英文展馆 + 冠名 logo
```

**行为**：

- 启动后隐藏全部界面，按巡游域自动逐站飞往（复用与手动巡游相同的运镜）
- `tour=all` 时四域**由内向外**轮转：行星系统 → 太阳系 → 银河系 → 宇宙 → 循环；域间切换经"域全景锚点 → 域起点天体"两步过渡
- **观众任意操作**（触摸/滚轮/按键）即暂停巡游并显示界面，可自由探索
- 暂停期间顶部中央显示角标"🎪 展馆模式（暂停中，N 秒后恢复）· 退出"——**90 秒**无操作自动恢复巡游（隐藏界面并立即推进下一站）；点"退出"回到常规模式
- 每次操作都会重置 90 秒倒计时

**两种进入方式**：

| 入口 | 全屏 | 适用场景 |
|---|---|---|
| 控制面板「🎪 启动展馆模式」按钮 | 请求全屏（浏览器拒绝时静默降级） | 现场布展，点一下即入 |
| `?mode=kiosk` URL | 不请求全屏（浏览器限制：无用户手势必被拒绝） | 开机自启/信息发布系统集成——配合浏览器 kiosk 启动参数（如 Chrome `--kiosk`）实现全屏 |

## 合作方 logo（`logo`）

```
?logo=https://example.com/logo.png
```

- 显示在页面右侧（右上 HUD 之下、右下信息面板之上），高 40px、最大宽 160px，等比缩放、不可交互
- **仅接受 https 协议**（http/data/javascript 一律拒绝），长度上限 2048 字符
- 图片加载失败自动隐藏，不产生任何报错
- **展馆模式隐藏界面时 logo 保持显示**（冠名场景专用语义）

## 界面语言（`lang`）

```
?lang=en    # 英文界面（界面、3D 天体标签、科普说明全部切换）
?lang=zh    # 中文界面
```

优先级：`?lang=` > localStorage 记忆值（键 `stellar-odyssey:locale`）> 默认中文。运行中也可随时用控制面板顶部的 **zh / EN** 按钮切换（切换即持久化）。

## 相关快捷键

| 键 | 功能 |
|---|---|
| `H` | 隐藏/显示全部界面（常规模式下可用；展馆模式激活时按键统一按"观众输入"处理） |
