# 科学性说明

星海奥德赛坚持"**科学准确性优先**"：所有天体物理参数基于真实科学数据，轨道计算使用开普勒定律；
同时为保证可视化体验做了必要的艺术化处理——**每一处艺术化都在应用内说明、代码注释或需求文档中明确登记**。
本文汇总两类内容，帮助你区分"真实"与"演示"。

## 🎨 艺术化处理登记

以下处理为保证可视化体验而引入，均已在应用内（HelpHint/面板文案）与代码注释登记：

### 尺度与几何

| 处理 | 原因 |
|---|---|
| 默认模式天体半径对数压缩夸大 | 真实比例下行星在轨道尺度不可见；开启真实比例模式（`R`）即如实呈现 |
| 矮行星与人造卫星额外放大 | 保证可辨识；真实比例下过小不可见属科学事实 |
| 奥尔特云边界压缩至 L2/L3 过渡位置 | 真实 2,000–100,000 AU 跨度过大 |
| L4 星系间距离对数压缩 | 保持同屏可见 |
| L3 特殊天体水平距离为示意 | 高度方向按真实银纬，水平距离兼顾构图 |
| 垂直展开（V）为观察辅助视觉夸大 | 指示线标注为未放大的银纬推算真实高度 |
| 太阳垂直振荡波浪 ×10 视觉放大 | 真实振幅仅 ±300 光年（轨道半径的 ~1%），不放大不可辨；真实比例模式不放大 |

### 时间

| 处理 | 原因 |
|---|---|
| 各层级差异化时间压缩比 | 行星自转与星系演化时间尺度相差 10+ 个量级 |
| 快周期天体（ISS 等）速率钳制减速显示 | 视觉转速超 0.5 圈/秒会闪烁，UI 提示"已减速显示" |
| 超新星频率加速 | 真实约每 50–100 年一次/星系；通知内附说明 |
| 耀斑时长减速呈现 | 真实数分钟事件按可观察节奏展开 |
| 天狼星双星 50 年互绕周期降速 | 速率钳制 |

### 视觉

| 处理 | 原因 |
|---|---|
| 恒星闪烁仅行星视角呈现 | 真空中恒星不闪烁（闪烁源于大气湍流），作为"地表视角"氛围保留 |
| 黑子/日珥尺寸与活动频率演示化放大 | 保证近观可辨；色球厚度夸大至 +1.5% |
| ISS 模型按形态启发式着色 | NASA 公版模型材质为统一灰色 |
| 阋神星/鸟神星/妊神星程序化纹理 | 无探测器实拍，基于反照率/颜色/光谱观测特征推测 |
| 体积星云为程序化密度场 | 只复现扇贝腔/暗湾/丝状结构等标志特征的相对方位与量级（如 M42 四特征），云体细节程序化生成，与真实天区存在差异 |
| M87* 光子环尺寸压缩 | 与 Sgr A* 真实质量比 ~1,500×，同屏呈现按 ~1.9× 压缩（盘倾角 17° 近正视形态保留） |
| 2MRS 点云三项失真 | 本动速度污染（星系团"指状效应"）、近距（cz≲1,000 km/s）距离误差可达数十%、银道带 \|b\|<5° 为尘埃消光观测限制非真实空洞——开关说明文案内登记 |
| 费米气泡可见光化 | 真实为伽马射线结构，以淡紫→品红弥散辉光艺术化呈现（形态参数真实） |
| HI 翘曲盘缘振幅放大 | 盘可视截断处真实振幅仅 ~0.3 kpc 侧视不可辨，放大至 3,000 ly（径向增长趋势仍取 Levine m=1 形态） |
| LMC 30 Doradus 放大 5× | 真实直径 ~600 ly 仅为 LMC 盘 2%，原比例不可辨（位置换算真实） |
| GRB 近观周期压缩 | 余辉真实演化数天–数月，压缩至 45 秒周期重放（R∝t^¼ 膨胀与幂律减暗关系保留）；喷流节点外移为视觉化非真实视超光速 |
| 引力透镜弧/星系团透镜 | 原型真实（Abell 370），SIS 屏幕空间偏转为示意 |

### 声音

| 处理 | 原因 |
|---|---|
| 全部音效为艺术化设计 | **真空无声**——应用内明确登记；行星环境音按各行星大气特征区分（水星/矮行星近真空几乎静音），太阳轰鸣/黑洞嗡鸣为氛围化表达 |

## 设计原则

1. **可视化与科学冲突时，明确登记**——不静默地"美化"数据
2. **默认模式重体验，真实比例模式重事实**——一键切换（`R`）
3. **推测内容标注推测**——如矮行星程序化纹理、天宫程序化几何
4. **数据来源可追溯**——信息面板与代码注释逐项登记

若你发现科学性问题，欢迎提 issue 指正。
