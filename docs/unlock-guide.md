## 购买与兑换（四通道）

### 通道一：支付宝扫码支付（推荐 · 支付后自动发码即时解锁）

1. 打开 [解锁页](https://stellar.guushu.com/unlock)，在档位表点击所选档位的
   「支付宝扫码支付」按钮。
2. 付款窗口中可选填**昵称**与**留言**（将公开展示于贡献者名单与贡献者宇宙，
   留空昵称显示「匿名用户」），点「生成付款码」。
3. 用支付宝「扫一扫」完成支付（手机端可点「在手机上打开支付宝付款」直接拉起）；
   二维码 30 分钟内有效，过期可一键重新生成。
4. 支付成功后页面**自动激活权益**并展示解锁 token——**请务必妥善保存 token**
   （换设备粘贴激活即可恢复权益）。

> 无需注册任何账号；金额以页面档位表为准。

### 通道二：微信赞赏码（人工核验 · token 经 Email 发送）

1. 在解锁页展开微信赞赏码，按所选**档位金额**支付。
2. 按解锁页的**邮件模板**（可一键复制或直接打开邮件客户端自动填好）发送兑换邮件至
   [stevenzearo@163.com](mailto:stevenzearo@163.com)，附**支付截图**与**交易时间**。
3. 人工核验后通常 48 小时内回信发送解锁 token 与直达激活链接，按「token 使用」一节激活
   （非即时；急用请走通道一支付宝扫码）。

### 通道三：爱发电（备选 · 订单号自动兑换）

需注册爱发电账号：

1. 在解锁页点「前往爱发电购买」——按档位金额购买（周卡/年卡为**商品**，月卡为**订阅方案**）。
2. 支付完成后复制**订单号**：爱发电 App 或网页「我的 → 订单」中找到该笔订单，复制订单号
   （14–40 位数字）。
3. 回到解锁页，在「爱发电订单号」输入框粘贴订单号，点「兑换」——校验通过即时激活，
   页面显示档位、到期日与剩余天数。

> 同一订单号可**重复兑换**：始终返回首次签发的同一 token（不叠加时长）——token 丢了凭订单号即可找回。

### 通道四：Ko-fi（海外备选 · 人工核验）

1. 前往 [ko-fi.com/howardzlh](https://ko-fi.com/howardzlh)，按档位对应的 **$ 金额**支付
   （week $1 / month $2.5 / year $13）。
2. 同通道二：邮件附支付凭证与交易时间，回信发送 token。

## token 使用与换设备

解锁凭证是一串 `SO1.` 开头的三段字符串（限时签名 token）：

- **激活**：兑换成功自动激活；人工通道回信的 token 在解锁页「已有 token？在此激活」粘贴后点「激活」；
  或直接打开回信中的直达链接 `https://stellar.guushu.com/unlock?token=…`（打开即激活）。
- **持久有效**：激活后保存在本浏览器（localStorage），刷新、关闭再打开均有效，日常浏览零联网校验。
- **换设备 / 换浏览器**：在已激活设备的解锁页点「**复制我的 token**」，到新设备的解锁页粘贴激活
  （同一 token 可在多设备使用）；也可用 `?token=` 直达链接。
- **妥存 token**：请自行保存 token 文本。丢失找回：爱发电订单凭订单号重新兑换即返回同一 token；
  支付宝渠道发邮件至 [stevenzearo@163.com](mailto:stevenzearo@163.com) 说明支付时间、金额与
  所填昵称，核对订单后回信找回；人工通道凭兑换邮件往来记录邮件找回。

## 到期与续费

- 到期后自动恢复免费体验（近观细节层/L3-L4 巡游重新锁定、演示与天体观察站恢复每日限次），**不自动续费**。
- 续期 = 重新购买任意档位并兑换，新 token 激活后即覆盖生效；token 之间**时长不叠加**。

## 退款口径

- **未兑换**的订单可全额退款：发邮件至 [stevenzearo@163.com](mailto:stevenzearo@163.com) 申请**原路退回**。
- **已兑换**订单如发生退款，对应解锁凭证将**同步失效**（联网设备约 5 分钟内生效）。
- 支付宝渠道支付成功即自动发码（即视同"已兑换"）：退款同样发邮件申请，请说明**付款时间与金额**
  （填过昵称/留言请一并附上以便定位订单）；核实后**全额原路退回**支付宝账户，通常即时到账，
  凭证随退款同步失效。
- 退款均为**全额**，不支持部分退款；不提供发票。

## 常见问题

**Q：爱发电订单号在哪里找？**
爱发电 App 或网页登录后进入「我的 → 订单」，找到对应订单复制订单号（14–40 位数字）。
解锁页输入框只接受纯数字，粘贴时注意不要带多余字符。

**Q：兑换失败提示对照**

| 页面提示 | 含义与处理 |
|---|---|
| 订单号应为 14-40 位数字 | 输入格式不对——从爱发电「我的订单」重新完整复制 |
| 订单号无效，请核对后重试 | 爱发电查不到该订单——确认复制的是**订单号**且无遗漏字符 |
| 订单未完成支付 | 订单尚未支付成功——完成支付后再兑换 |
| 订单金额不足最低档位（¥6） | 实付金额低于周卡价——补齐档位金额后用新订单兑换 |
| 该订单对应的商品不支持解锁兑换 | 该订单购买的不是解锁档位商品——仅「星海征程」周卡/月卡/年卡三档商品/方案的订单可兑换，请核对后用解锁档位订单重试 |
| 该订单已被兑换过 | 幂等保护：本人换设备请用原 token 激活（重复兑换会返回同一 token，直接粘贴订单号再兑一次即可取回） |
| 订单查询服务暂时不可用 | 上游（爱发电）接口波动——稍后重试 |
| 兑换服务尚未开通 | 服务端未配置完成——稍后再来或邮件联系 |
| 网络请求失败 | 本机网络问题——检查网络后重试 |

**Q：粘贴 token 报错？**

| 提示 | 处理 |
|---|---|
| token 格式不正确 | 确认完整复制：`SO1.` 开头、共三段、中间无换行/空格截断 |
| token 签名校验失败 | token 内容被改动过——重新从来源（复制按钮/回信/直达链接）完整复制 |
| token 已过期 | 权益已到期——重新购买任意档位续期 |
| 这枚凭证已随退款静静熄灭 | 该 token 对应订单已退款，凭证同步失效——愿意再度启程时可重新购买任意档位 |
| 未能核验凭证状态 | 首次在此设备激活需联网核验一次——检查网络连接后重试 |

**Q：清除权益是什么？会退款吗？**
解锁页的「清除权益」只是从本浏览器移除已激活的 token（例如公用电脑离开前清理），
与退款无关；再次粘贴 token 即可恢复。

**Q：支付宝扫码支付后没有自动解锁？**
支付成功后页面通常数秒内自动激活；若长时间停留在"等待支付确认"，请保持页面打开——
系统会自动向支付宝实时核对订单并补发。**已完成支付但页面已关闭时请勿重新支付**：
邮件说明支付时间、金额与所填昵称即可找回 token。

**Q：解锁和捐赠页是什么关系？**
统一为"支持即解锁"：支付任意档位即解锁对应天数，昵称与留言（均可选）记入
[捐赠名单](https://stellar.guushu.com/donate)与[贡献者宇宙](https://stellar.guushu.com/contributors)。
捐赠页（/donate）汇总全部支持通道，其中支付宝扫码入口会引导回本解锁页完成支付。
