## 购买与兑换（三通道）

### 通道一：爱发电（自动兑换，推荐）

1. 打开 [解锁页](https://stellar.guushu.com/unlock)，点「前往爱发电购买」——按档位金额购买
   （周卡/年卡为**商品**，月卡为**订阅方案**）。
2. 支付完成后复制**订单号**：爱发电 App 或网页「我的 → 订单」中找到该笔订单，复制订单号
   （14–40 位数字）。
3. 回到解锁页，在「爱发电订单号」输入框粘贴订单号，点「兑换」——校验通过即时激活，
   页面显示档位、到期日与剩余天数。

> 同一订单号可**重复兑换**：始终返回首次签发的同一 token（不叠加时长）——token 丢了凭订单号即可找回。

### 通道二：微信赞赏码（人工兑换）

1. 在解锁页展开微信赞赏码，按所选**档位金额**支付。
2. 发送兑换邮件至 [stevenzearo@163.com](mailto:stevenzearo@163.com)，附**支付截图**与**交易时间**。
3. 通常 48 小时内回信发送解锁 token 与直达激活链接，按「token 使用」一节激活。

### 通道三：Ko-fi（人工兑换）

1. 前往 [ko-fi.com/howardzlh](https://ko-fi.com/howardzlh)，按档位对应的 **$ 金额**支付

2. 同通道二：邮件附支付凭证与交易时间，回信发送 token。

## token 使用与换设备

解锁凭证是一串 `SO1.` 开头的三段字符串（限时签名 token）：

- **激活**：兑换成功自动激活；人工通道回信的 token 在解锁页「已有 token？在此激活」粘贴后点「激活」；
  或直接打开回信中的直达链接 `https://stellar.guushu.com/unlock?token=…`（打开即激活）。
- **持久有效**：激活后保存在本浏览器（localStorage），刷新、关闭再打开均有效，日常浏览零联网校验。
- **换设备 / 换浏览器**：在已激活设备的解锁页点「**复制我的 token**」，到新设备的解锁页粘贴激活
  （同一 token 可在多设备使用）；也可用 `?token=` 直达链接。
- **妥存 token**：请自行保存 token 文本。丢失找回：爱发电订单凭订单号重新兑换即返回同一 token；
  人工通道凭兑换邮件往来记录邮件找回。

## 常见问题

**Q：爱发电订单号在哪里找？**
爱发电 App 或网页登录后进入「我的 → 订单」，找到对应订单复制订单号（14–40 位数字）。
解锁页输入框只接受纯数字，粘贴时注意不要带多余字符。

**Q：兑换失败提示对照**

| 页面提示 | 含义与处理 |
|---|---|
| 订单号应为 14-40 位数字 | 输入格式不对——从爱发电「我的订单」重新完整复制 |
| 订单号无效，请核对后重试 | 爱发电查不到该订单——确认复制的是**订单号**且无遗漏字符 |
| 订单未完成支付 | 订单尚未支付成功——完成支付后再兑换 |
| 订单金额不足最低档位（¥6） | 实付金额低于周卡价——补齐档位金额后用新订单兑换 |
| 该订单已被兑换过 | 幂等保护：本人换设备请用原 token 激活（重复兑换会返回同一 token，直接粘贴订单号再兑一次即可取回） |
| 订单查询服务暂时不可用 | 上游（爱发电）接口波动——稍后重试 |
| 兑换服务尚未开通 | 服务端未配置完成——稍后再来或邮件联系 |
| 网络请求失败 | 本机网络问题——检查网络后重试 |

**Q：粘贴 token 报错？**

| 提示 | 处理 |
|---|---|
| token 格式不正确 | 确认完整复制：`SO1.` 开头、共三段、中间无换行/空格截断 |
| token 签名校验失败 | token 内容被改动过——重新从来源（复制按钮/回信/直达链接）完整复制 |
| token 已过期 | 权益已到期——重新购买任意档位续期 |

**Q：清除权益是什么？会退款吗？**
解锁页的「清除权益」只是从本浏览器移除已激活的 token（例如公用电脑离开前清理），
与退款无关；再次粘贴 token 即可恢复。

**Q：解锁和赞助是一回事吗？**
不是。解锁是明码标价的限时访问对价（付 ¥X 得 Y 天），赞助（[/donate](https://stellar.guushu.com/donate)）
是零回报的自愿支持——两者相互独立，赞助不构成解锁条件，解锁也不算入赞助名单。
