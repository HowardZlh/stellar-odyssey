# 四视角导览

星海奥德赛的世界由四个层级组成，按 `1`–`4` 一键直达，或用滚轮连续缩放无缝穿越。
每个视角有专属的内容、时间压缩比、音景与控制面板选项。

```
L1 行星视角 ──滚轮──> L2 太阳系视角 ──滚轮──> L3 银河系视角 ──滚轮──> L4 宇宙视角
   ~行星尺度              ~50 AU               ~10 万光年            ~数亿光年
```

> 说明：L3/L4 的巡游序列（`[` / `]`）与近观细节层（光子环/体积星云内部/星系近观粒子等）
> 为支持者限时解锁内容——免费体验可远观全部天体并查看信息面板科普，L1/L2 完整不受限。
> 范围、档位与兑换见[支持者解锁](unlock-guide.md)。

## L1 · 行星视角 🌍

**看什么**

- 行星表面细节：地球大陆/海洋/云层/夜半球城市灯光、火星极冠与水手号峡谷、木星云带与大红斑差速流动、土星环与卡西尼缝……全行星 4K 纹理 + 法线贴图近观立体细节
- 卫星系统：月球（潮汐锁定，始终同面朝向地球）、ISS/哈勃/静止卫星/天宫（近观 glTF 精细模型，对地定向姿态与帆板对日）、伽利略四卫星 1:2:4 共振、土卫六土卫二
- 恒星闪烁背景（仅本视角呈现——真空中恒星不闪烁，闪烁源于大气湍流，属艺术化处理）

**怎么玩**

- `]` / `[` 在**当前行星系统内**巡游（如地球系统 6 站：地球→天宫→ISS→哈勃→静止卫星→月球；跟随木星时在伽利略卫星间循环）
- 面板勾选**卫星轨道线**（本视角专属选项）
- 触发**耀斑 / CME 演示**（与 L2 共享）
- 开启真实比例模式（`R`）感受卫星的真实渺小

## L2 · 太阳系视角 ☀️

**看什么**

- 八大行星 + 矮行星（冥王星/谷神星/阋神星/鸟神星/妊神星）+ 彗星（哈雷/恩克）沿真实开普勒轨道运转，初始位置与真实当前日期一致
- 小行星带（2.2–3.2 AU）与柯伊伯带：每个粒子独立开普勒轨道，内圈快外圈慢（开普勒剪切）
- 太阳活动：黑子（11 年周期蝴蝶图迁移）、日珥、光斑、较差自转；奥尔特云外边界示意；日球层顶三层结构（终端激波/日鞘）+ 旅行者 1/2 号标记
- 哈雷彗星近日点附近彗发与双彗尾（蓝色离子尾 + 黄白尘埃尾，始终背向太阳）

**怎么玩**

- `]` / `[` 按轨道半长轴升序巡游 15 天体（行星+矮行星+彗星）
- 点选太阳 → 面板勾选**太阳内部剖面**（本视角专属）：1/4 切除视图，核心/辐射区/对流区可点选科普
- 触发**耀斑 / CME 演示**，CME 朝地球时可观察抵达后的极光增强
- 加速时间观察行星公转与哈雷彗星 76 年周期

## L3 · 银河系视角 🌀

**看什么**

- 3D 棒旋结构：核球 + 4.3 万粒子银盘 + 密度波旋臂（旋臂图案与恒星较差自转不同步）+ 尘埃带 + 银晕 + **HI 翘曲盘**（外盘 S 形垂直翘曲，侧视可辨）+ **费米气泡**（银心上下双极辉光，可开关）
- 太阳系的位置与运动："You are here" 标记（距银心约 2.6 万光年），沿波浪轨道绕银心公转（垂直振荡视觉放大 ×10 已登记），HUD 显示银河年进度（一圈约 2.3 亿年）
- 14 站深空巡游天体（真实原型 + SIMBAD 银纬定位），**每一站都值得飞抵推近**：
  - **体积渲染星云**（raymarch 发射-吸收）：猎户座 M42（扇贝状发射腔 + 四边形星团空腔，Hα 红/OIII 青绿双色）、环状星云 M57 壳层、马头星云吸收暗云剪影、蟹状星云丝状遗迹 + 脉冲星风云环面与极向喷流、WR 124 星风抛射壳
  - **引力透镜黑洞**：人马座 A* 与天鹅座 X-1——推近可见光子环、背景星场弯曲、吸积盘温度黑体色 + 多普勒束流增亮 + 引力红移
  - **物理化恒星表面**：参宿四（橙红黑体色 + 非对称巨对流胞 + 衍射星芒）、参宿七/天狼星 A（蓝白）、天狼星 B 白矮星、造父一脉动变星——颜色由 Planck 黑体谱定，临边昏暗随光谱型分档
  - **真实星表星团**：昴星团（Gaia DR3 视差+自行选出的 600 颗真实成员星 + 蓝色反射星云）、M13 球状星团（King 分布 + HR 图颜色）

**怎么玩**

- `]` / `[` 巡游 14 站（日球层顶 → 人马座 A* → 参宿四 → …… → 昴星团 → M13），逐一飞往近观；**跟随后继续滚轮推近**才能看到光子环/体积星云内部等近观细节层
- `G` **银心固定视角**（本视角专属区块）：银心居中不动，俯瞰太阳系沿波浪轨道绕银心公转，静止的银河年刻度从原点滑过
- `V` **垂直展开**（本视角专属）：整个银盘 morph 为扁旋转椭球体，特殊天体按真实银纬高度展开并显示高度指示线；增益滑块 ×1–×6 可调
- 触发**超新星演示**（本视角专属）：完整四阶段爆炸动画，结束后留下永久遗迹（中子星或黑洞）

## L4 · 宇宙视角 🌌

**看什么**

- 本星系群：银河系（费米气泡 + HI 翘曲盘同样可见）、仙女座 M31（含伴星系 M32/M110）、三角座 M33、大小麦哲伦云（沿轨道运动 + 麦哲伦星流）、人马座矮星系（潮汐拖尾 + 人马座潮汐流）
- **影像驱动的星系近观**：飞抵 M31/M33/大小麦哲伦云，远景照片贴图交叉淡入 3D 粒子云——旋臂走向、尘埃暗带、恒星形成区均由 DSS2 真实巡天影像烘焙驱动，与照片逐一对应；斜视 M31 时近侧**体积尘埃盘真实遮挡**后方星光（视线消光）；LMC 近观可辨 **30 Doradus 蜘蛛星云**（Hα 粉红发射区 + R136 亮核）与偏黄中央棒
- **真实巡天背景（2MRS）**：43,488 个真实星系的三维点云替代示意宇宙网——室女座团方向的星系聚集、银道遮挡带、纤维状大尺度结构均为真实数据（可开关，附三项失真说明）
- 银河系—仙女座以 ~110 km/s 相互接近（连线轨迹 + 流动光点 + 碰撞倒计时约 45 亿年）
- 更大尺度：室女座星系团中心 **M87**（椭球星光 + 2,000 球状星团 + HST-1 类节点喷流 + 室女座成员点缀；**继续推近核心可见 EHT 2019 同款近正视光子环**）、类星体 3C 273（吸积盘 + 尘埃环面近观）、触须星系（N-body 潮汐尾近观）、Abell 370 型引力透镜弧（跟随时屏幕空间透镜扭曲背景）、**GRB 221009A**（相对论双喷流 + 余辉膨胀壳周期演示）、拉尼亚凯亚超星系团边界与巨引源方向、可观测宇宙边界圈层（半径约 465 亿光年）
- 哈勃膨胀示意：点云与宇宙网随时间整体缩放，遥远星系红移变红

**怎么玩**

- `]` / `[` 巡游 8 站星系（银河系 → 大小麦哲伦云 → 人马座矮 → M31 → M33 → M87 → 3C 273），逐站飞抵后**继续滚轮推近**看近观细节层（M87 推近至核心触发 EHT 光子环）
- 触发**合并预览**（本视角专属）：⏩ 12 秒快进 45 亿年，完整呈现银河系—仙女座首次穿越 → 回摆振荡 → 潮汐扭曲 → 星暴 → 终态椭圆星系 Milkomeda；一键 ⏪ 恢复预览前时间
- 面板勾选**真实巡天背景（2MRS）**/**费米气泡**/**速度矢量箭头**（域内专属开关）
- `O` 开关卫星星系轨道线；加速时间观察大小麦哲伦云绕银河系运动

## 跨视角机制

| 机制 | 说明 |
|---|---|
| **连续缩放** | 滚轮驱动连续层级（1.0–4.0），内容 LOD/时间压缩比/背景色/音景全部平滑插值 |
| **近观细节层** | 体积星云/黑洞透镜/星系近观粒子等重资产按"跟随 + 距离阈值"懒挂载，退出即释放（LRU 池管理，显存可控）——**跟随后继续推近**是解锁近观细节的通用玩法 |
| **自适应质量** | 体积渲染按滑动窗 FPS 自动升降档（步数 + 渲染分辨率），低端设备平滑降档 |
| **层级锁定** | 跟随/飞往天体期间视角层级锁定为所属域（跟随 L3 天体拉近不会误跳视角），按 `1`–`4` 或 `Esc` 解锁 |
| **时间压缩** | 各层级差异化压缩比（行星视角看自转、宇宙视角看星系演化），跨层级对数插值 |
| **面板作用域** | 视角专属选项只在对应视角显示（域外隐藏但状态保留——如 L3 开启垂直展开后切 L4，银河系仍呈椭球） |
| **事件域** | 动态事件按视角域隔离：离开所属域超 1 秒事件被丢弃，域内才会自动触发（见 [events-guide.md](events-guide.md)） |
| **展馆模式** | 四个视角域均可自动巡游（`tour=all` 由内向外轮转全部四域），任意操作暂停、片刻无操作恢复（见 [launch-params.md](launch-params.md)） |
